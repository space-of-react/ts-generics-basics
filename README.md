# TypeScript: дженерики

## Установка

```bash
npm install
```

## Как запускать задания

```bash
npm run task:07       # задание 07
npm run solution-07   # его решение
```

Обе команды открывают Vitest UI в браузере и одновременно печатают результат в
терминал.

## Как проходить курс

В файле `*.проблема.ts` лежит код, который не компилируется. Комментариев в нём
нет: постановка задачи — это текст ошибки компилятора, а не пересказ над кодом.
Внизу каждого задания стоят экспортированные строчки с использованием — то, ради
чего всё и затевается. Пока тип неправильный, они подчёркнуты красным; когда
правильный — ошибка уходит сама.

В части заданий рядом стоит и обратное использование: вызов, который компилятор
ОБЯЗАН отвергнуть, помеченный `@ts-expect-error`. Пока задание не решено, ошибки
нет — и красным подчёркнута сама директива, с сообщением про неиспользованную.
Это тот же сигнал провала, просто вывернутый наизнанку.

1. Запусти задачу:

    ```bash
    npm run task:01
    ```

2. Открой файл в `src/` и прочитай ошибку компилятора. **Она и есть постановка
   задачи** — читай её, а не подбирай типы наугад. Красное есть в каждом
   `*.проблема.ts`: где-то в теле функции, где-то в использовании внизу.

3. Проверь результат в Vitest UI. Часть тестов сравнивает сами типы
   (`expectTypeOf`), часть проверяет поведение в рантайме (`expect`).

4. Сравни с решением:

    ```bash
    npm run solution-01
    ```
